# FareSniper Frontend

Next.js app router frontend for FareSniper.

## Scripts

- `npm run dev`
- `npm run build`
- `npm run start`
- `npm run lint`

## Deploy

This frontend is intentionally kept on the standard Next.js production flow so Railway can continue using:

- build: `npm run build`
- start: `npm run start`

No Google or Firebase services are required for this frontend to boot locally or on Railway.
